# Cleaning-Spanish-census
Cleaning and renaming Excel files from Spanish national census since year 2000 until most recent data

(Data from years 96,98 and 99 must be manually removed, or ignored)


This Python script will upgrade the .xls files to .xlsx, change the name of the files using the year, and it will clean the firts lines that
have a not necesary comment

It will change the column names, to include the year in some of them.

After that, the data will be nearest to be ready for include them in a Database.
